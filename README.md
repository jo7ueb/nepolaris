# nepolaris

**Personal Financial Observatory**

複式簿記を基盤として、個人の財務状態を継続的に観測・分析し、よりよい意思決定につなげるセルフホスト型Webアプリケーション。

> **開発初期段階：** 本リポジトリは設計・要求整理から開始しています。会計処理機能はまだ実装されていません。

## なぜ作るのか

家計簿で支出を記録することは目的の一部にすぎません。本当に必要なのは、預貯金、証券、FX、iDeCo、負債、日常の収支を一つの会計体系として扱い、純資産の増減とその要因を理解できることです。

既存の家計簿アプリは生活支出を把握するには便利でも、財務諸表・資産配分・管理会計の観点を一貫して扱えるとは限りません。一般的な複式簿記ソフトは帳簿に強い反面、日常的な観測と意思決定に適したUIを必ずしも備えていません。

nepolaris は **財務会計を確かな土台とし、管理会計を主役に据える** ことを目指します。

## 設計原則

- **正しい帳簿：** 内部は厳密な複式簿記。すべての仕訳で借方・貸方が一致する。
- **少ない入力：** 金融機関APIには依存せず、CSVインポートと月末の評価額入力を中心に運用する。
- **取引履歴を要求しすぎない：** FX・証券・iDeCoのすべての売買を記録する必要はなく、口座間資金移動と月末評価額で全体財務を管理する。
- **根拠を追える：** 元CSV・評価入力・仕訳・訂正履歴を関連付け、照合できるようにする。
- **観測から意思決定へ：** B/S、期間収支、純資産推移、資産配分、流動性、予実などの可視化を重視する。
- **個人用・セルフホスト：** Dockerで気軽に起動でき、データを自分で保有・バックアップ・エクスポートできる。

## 想定する基本的な使い方

1. 銀行等から取引CSVをダウンロードし、nepolarisに取り込む。
2. 取引の分類・口座間振替・重複を確認し、仕訳を確定する。
3. 月末にFX・証券・iDeCoなどの口座純資産／評価額を入力する。
4. 残高照合と評価調整仕訳を確認して月次決算する。
5. 財務諸表とダッシュボードで資産の状態・変化を確認する。

## まだやらないこと

金融機関API・スクレイピング、全投資約定の追跡、税務申告ソフトの代替、自動売買、多人利用を初期スコープに含めません。

## 技術方針（未確定）

小規模・ローカルファーストのWebアプリをDocker Composeで実行する構想です。バックエンド・フロントエンド・DBの具体的な選定はアーキテクチャ検討Issueで決めます。
